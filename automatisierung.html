Fragen an meinen Lebenslauf: Chat-Assistent mit Quellenbindung

Ein Assistent, der Fragen zum Werdegang beantwortet und dabei nur aus zwei Quellen schöpfen darf: dem Lebenslauf und drei Fallstudien. Er antwortet in der dritten Person, nennt zu jeder Antwort den Abschnitt, aus dem sie stammt, und sagt offen, wenn etwas nicht dokumentiert ist. Nach jeder Änderung am Prompt läuft er gegen fünfzehn Testfragen: erfundene Arbeitgeber, Einschleusen von Regeln im Gesprächsverlauf, eine Kontrollfrage, deren Antwort nur in den Quellen stehen kann. Das Modell wurde per Test ausgewählt, der Server läuft bei einem deutschen Hoster, die Antworten werden gestreamt. Der gesamte Verlauf bleibt im Browser.

Python · FastAPI · Claude · NDJSON-Streaming · Caddy · systemd

Self-Talk-Coach: Gesprächspartner für gesprochenes Deutsch

Ein Gesprächspartner für gesprochenes Deutsch von der Kommandozeile. Ich drücke die Leertaste, spreche, Deepgram transkribiert, ein Sprachmodell antwortet als Gesprächspartner und edge-tts liest die Antwort vor. Stocke ich nach einer Frage, greift eine Hilfsleiter: erst eine Ermutigung, dann ein Satzanfang, dann die Frage in einfacher Form. Jede Runde landet mit Timing in SQLite, am Ende gibt es die mediane Reaktionszeit. Dazu eine Mediathek, die eigene Selbstgespräch-Videos lokal mit faster-whisper transkribiert. Privat, weil er gegen meine eigenen Sprechdaten läuft.

Python · Deepgram · faster-whisper · edge-tts · SQLite
Repository privat, gern zeige ich es im Gespräch.

Anny-Booking-Bot: Tagesübersicht für Buchungen

In unserem Wohnhaus buchen Bewohner eine Gemeinschaftsküche über anny.co. Der Hausmeister soll jedem die Küche übergeben, sieht die Buchungen aber nur, wenn er sich selbst anmeldet. Der Bot meldet täglich um fünf Uhr morgens per Playwright ohne Oberfläche an, liest die heutigen und morgigen Buchungen und schickt eine aufbereitete Mail an den Hausmeister: Uhrzeit, Name, Telefonnummer, Raum. Geplant über GitHub Actions und einen externen Cron-Dienst, geprüft mit pytest und CI. Lief mehrere Monate täglich.

Python · Playwright · Gmail SMTP · GitHub Actions · pytest

Tägliche Stellenbenachrichtigung für SmartRecruiters

Stellenportale zeigen Neues nur nach dem Einloggen, und täglich nachschauen ist Arbeit, die ein Skript übernehmen kann. Der Bot fragt die Suchergebnisse von SmartRecruiters ab, gleicht sie mit dem Stand von gestern ab und schickt eine Mail nur dann, wenn etwas neu dazugekommen ist. Python, GitHub Actions als Cron, kein Server, kein API-Schlüssel. Lief fünf Monate täglich.

Python · GitHub Actions · HTML-E-Mail
