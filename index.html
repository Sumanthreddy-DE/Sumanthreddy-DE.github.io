Selected work

PINN for composite interface identification

Master thesis, submitted February 2026, defended March 2026

A physics-informed neural network that solves an inverse problem: given the effective bulk and shear moduli of a three-layer interphase in a fibre-reinforced composite, it recovers the interface parameters that reproduce them. Accuracy came from correcting mislabelled boundary cases, adaptive loss weighting and gradient clipping.

PyTorch, NumPy, SciPy

SimReady

March 2026 to present

An assistant for FEA pre-processing. It runs twelve geometry checks over a STEP file, scores whether the part is ready to mesh, and explains each finding in chat with the affected faces highlighted on the model. A graph neural network trained on generated parts predicts which CAD faces need mesh refinement, using each face neighbours as context.

PyTorch Geometric, pythonocc, LLM fine-tuning, Streamlit

NX constraint to joint classification

Chair of Engineering Design (KTmfk), FAU, 2025 to 2026

A transformer model that maps Siemens NX assembly constraints to the matching NX Motion joint, framed as supervised classification. The training set was built from scratch by parsing public STEP files into constraint and joint pairs.

TensorFlow, NXOpen API, Siemens NX

Peak power minimization under harmonic loads

September 2024

A Python reimplementation of a published semidefinite programming method for truss topology optimization, solved with MOSEK. The work included diagnosing why the reference implementation behaved differently from its paper.

Python, FEM, PICOS, MOSEK
